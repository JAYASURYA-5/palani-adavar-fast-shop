# Palani Andavar Fast Food — Landing Page

A responsive, video-led restaurant landing page made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling and motion
- `script.js` — mobile navigation, reveal animations, video playback
- `assets/hero-food-video.mp4` — 16:9 food video used in the hero
- `assets/food-preparation-portrait.mp4` — portrait preparation video for the story section
- `assets/signature-chicken.jpg` — uploaded food photo
- `assets/palani-andavar-logo.jpg` — uploaded logo artwork

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Run `index.html` using the Live Server extension for the best local experience.

You can also open `index.html` directly in a modern browser, although a local server is recommended for video playback.

## Before publishing
- Confirm that the menu, phone number, exact address, prices, and ordering URL are correct.
- Replace any placeholder contact details with the real business information.
- Consider compressing the video files for faster mobile loading.
- The supplied logo image has a black background and is used as a circular image in the header. For the cleanest result, use a transparent PNG logo if available.
